## Description

Divide a surface into a quad mesh using parameters

## Inputs

- Surface (S) - [surface] - Surface to divide
-  X Parameter (tX) - [number] - Range of numbers (0-1) for X divisions
-  Y Parameter (tY) - [number] - Range of numbers (0-1) for Y divisions

## Outputs

- Quad Mesh (M) - [mesh] - Quad mesh
