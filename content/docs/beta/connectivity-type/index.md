## Description

A collection of pre-made unit cells and their connectivity. This is a derivative of the [Cell Type](/Crystallon/docs/populate/cell-type/) component that includes additional mesh output

## Inputs

- Connectivity Selector (Connectivity Selector) - [generic data] - Index of unit cell geometry to populate

## Outputs

- Name (Name) - [generic data] - Name of the unit cell
- Unit Cell (Unit Cell) - [generic data] - Unit cell curves
- Unit Cell Connectivity (Unit Cell Connectivity) - [generic data] - Mesh defining how elements of the unit cell should be connected to one another
