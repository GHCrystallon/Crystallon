## Inputs

- Curve (C) - [curve] - Curve to graph (draw on XY plane)
- Range (R) - [number] - Range of numbers (0-1)
- Preview Gradient (G) - [boolean] - Contains a collection of boolean values
- Preview Tags (T) - [boolean] - Contains a collection of boolean values

## Outputs

- Numbers (N) - [number] - Remapped Range
