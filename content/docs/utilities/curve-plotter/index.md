## Inputs

- Y Values (Y) - [number] - Range of numbers
- X Values (X) - [number] - Range of numbers
- Length (L) - [number] - X dimension of plot
- Height (H) - [number] - Y dimension of plot

## Outputs

- Polyline (P) - [curve] - Output Polyline
- Interpolate (I) - [curve] - Output interpolated curve
