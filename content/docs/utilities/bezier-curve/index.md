## Inputs

- Points (P) - [point] - Contains a collection of three-dimensional points
- Tanget Length (L) - [number] - Multiplier for tangent length (one number per span)
- Tanget Rotation (R) - [number] - Tangent rotation in radians (one number per span)

## Outputs

- Curve (C) - [curve] - Bezier Curves
